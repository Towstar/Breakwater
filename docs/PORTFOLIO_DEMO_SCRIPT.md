# Portfolio demo narration

About 90 seconds at a measured speaking pace. Use the self-authored portfolio
examples and prepare the local comparison and retained hosted trace before
recording. A recording is historical evidence, not a fresh hosted request. This
narration does not depend on a particular cost result.

---

Breakwater is a desktop application for understanding fluid networks and testing
responses to operating incidents.

This is Sandbox, our editable 3D workspace. Tanks, sources, pumps and routes have
stable identities and explicit settings. Moving equipment changes the layout.
Numerical or topology changes make previous results stale and retire approval
eligibility.

Here, a pump failure causes the no-action forecast to cross a storage limit. We
keep that overflow visible. Local search evaluates a bounded set of responses,
and an independent validator checks the selected candidate. The comparison shows
trajectories, costs and remaining margins. Applying simulated controls requires
an explicit review of the exact run, validation and proposed settings.

Operations imports network, policy and timestamped observation files.
The chart preserves original units, missing readings and out-of-range values.
Its cutoff is a recorded-data clock, not a live plant connection.

Nemotron is the optional investigation agent. It chooses real tools, receives
their numerical results and selects evidence to support a recommendation. This
trace is retained evidence from an earlier hosted investigation. Opening it
makes no new model request and restores no approval authority.

Lucas led the desktop, 3D interaction, agent integration and evidence workflows.
Ethan led simulation, search, validation, science and formal algorithm checks.
Codex assisted implementation and testing.

Breakwater is a synthetic decision-support prototype, with transparent assumptions
and inspectable evidence. It does not dispatch equipment or control a real plant.
