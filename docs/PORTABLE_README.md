# Breakwater Windows portfolio candidate

Double-click **Start-Breakwater.cmd**. Sandbox opens with a synthetic editable
network. No installed Python, Qt SDK, API key, Torch or PhysicsNeMo is required.

Try Project → Pump failure example → Run forecast. Investigate → Local search
runs real numerical tools without a model. Compare results and inspect the
explicit review action before applying simulated controls.

Switch to Operations → Examples → Synthetic operations demo. Search plans and
Validate exact plan run against an immutable capture. Recorded Nemotron
investigation opens a genuine historical session and performs no new model call.
The renamed/topology-changed example requires fresh analysis. EOG-format data
imports through Open dataset by choosing the folder containing network.json,
ops.json and telemetry.csv.

See [the walkthrough](PORTFOLIO_WALKTHROUGH.md) and
[the examples](share/breakwater/examples/README.md). All examples are self-authored
and synthetic; layout supplies no pressure hydraulics or travel times.

Double-click **Verify-Breakwater.cmd** for isolated rendering, real local search,
independent validation and historical reopening checks. It also exercises the
installed stdlib publisher through desktop acquisition, immutable capture,
native search and advisory acknowledgement, without applying controls or using a
model key/Torch. It writes logs and images
to a new sibling verification folder. A clean Windows account/VM remains a
separate release gate; sanitized developer-process tests do not establish it.

For optional Science, extract the matching source archive and use its documented
Setup-OptionalScience.ps1 workflow with PowerShell 7. Set BREAKWATER_PYTHON to the
resulting absolute Python executable, then use **Start-Breakwater-Science.cmd**.
The basic bundle contains no Torch/PhysicsNeMo. Invalid explicit overrides fail
visibly. No API key belongs in a project, archive or source commit.

This is a local review candidate. Public distribution awaits both owners' GPLv3
agreement, notices/corresponding-source review and clean Windows verification.
See [LICENSING](LICENSING.md), files-sha256.json, the matching source ZIP and
the package verification report. No public GitHub release was created.
