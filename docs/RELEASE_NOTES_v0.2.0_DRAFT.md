# Breakwater v0.2.0 release notes, draft

**Local review candidate only. Do not publish these assets until the gates below
are complete.** Candidate application source is `ad45d45`; later documentation
commits do not relabel its binary. No GitHub release or tag has been created.

## Prepared behavior

- Sandbox-led Windows desktop with an editable industrial 3D workspace, equipment
  navigator/filter, unit-aware inspector, camera controls and bounded overview detail.
- Native constant-flow forecasts, uncut negative/overflow trajectories, compatible
  run comparisons, bounded local response search and exact independent validation.
- SQLite evidence retention, versioned session import/export and explicit
  simulated control review. Historical evidence cannot restore action eligibility.
- Operations recorded-data viewing, original-unit observations, local plan search,
  separate validation and optional genuine hosted Nemotron investigation.
- Minimal isolated Python in the portable bundle. Optional Torch/PhysicsNeMo
  remains a separate pinned CPU setup for sensitivity and bounded tracer fitting.
- Windows logo icon, shared dialogs/docks, offline self-authored examples and
  seven actual candidate screenshots.

The packaged live-check CLI now initializes the bundled Python exactly as the
desktop does. Explicit incompatible interpreter overrides remain visible failures.
Numerical/scientific/proof implementations were not changed by this readiness fix.

## Qualification and limitations

All six Windows CI jobs and nine relocated portable checks pass for `ad45d45`.
Fresh hosted qualification is 3/4, with one invalid final JSON correctly rejected;
its all-four gate remains incomplete. Real optional Science passes separately.
See the [exact counts, skips, failures and source scope](evidence/portfolio/release-readiness/README.md).

All operating data/costs are synthetic. Layout supplies no pressure hydraulics;
search is bounded best-found rather than globally optimal. Standalone Lean
assumptions and sanitizer results do not qualify a real plant. Optional scalar
tracer fitting is not calibrated field chemistry. Generic observed-state forecasts
and evolving commitment-aware fleet dispatch remain subsequent increments.
